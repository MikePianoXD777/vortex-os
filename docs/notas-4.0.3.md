# Vortexine's OS 4.0.3

## Arreglado

### A veces el clic en un escritorio de la barra no cambiaba de escritorio

El clic solo contaba justo encima de la pastilla del escritorio, que mide 18 px. Si le dabas un poco más
arriba, más abajo o en el hueco entre dos escritorios, no pasaba nada.

- **Ahora cuenta todo el alto de la barra y la mitad del hueco hacia cada lado**, en los tres estilos de
  escritorios (pastillas, números y Pac-Man).

## Para actualizar

```
vortex actualizar
```

Al terminar, el shell se reinicia solo.
