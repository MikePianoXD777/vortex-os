# Vortexine's OS 2.3.1

Dos arreglos de Vortexine Task Manager, encontrados al probarlo en vivo.

## Arreglos

- **Supr ya finaliza después de buscar.** Al hacer clic en un proceso, el buscador se quedaba con el
  teclado y Supr (o Mayús+Supr) no hacía nada. Ahora el clic pasa el teclado a la lista.
- **«Finalizar tarea» cierra también lo que está en pausa.** Un proceso en pausa no atiende la orden de
  terminar hasta que lo reanudan; ahora se reanuda solo para que termine, como en Windows.

## Para actualizar

```
vortex actualizar
```
