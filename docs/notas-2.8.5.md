# Vortexine's OS 2.8.5

## Lo arreglado

- **Cursor invisible en laptops.** En algunas laptops, sobre todo con dos gráficas, el cursor por hardware no se dibujaba.
  Ahora los equipos con batería dibujan el cursor por software. Las PC de escritorio se quedan igual. Si prefieres otro
  valor, ponlo en `~/.config/vortex/hypr-mio.lua`, que gana sobre este ajuste.

## Para actualizar

`vortex actualizar`. El cambio se aplica solo al terminar.
